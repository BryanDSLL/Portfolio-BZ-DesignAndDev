# Bryan Zimbrão — Portfolio

> **Frontend Architect & Creative Developer**  
> Interface moderna, fluida e de alta performance construída com React 19, Vite, Tailwind CSS, Framer Motion e GSAP.

---

## 🚀 Tecnologias e Bibliotecas

- **React 19** + **TypeScript** + **Vite**
- **Tailwind CSS** para estilização utilitária e design system
- **GSAP & ScrollTrigger** para animações de parallax em camadas e scroll
- **Framer Motion** para animações fluidas de microinterações e transições
- **Lenis Scroll** para rolagem suave (smooth scrolling)
- **Zustand** para gerenciamento de estado global (idioma, tema)
- **Lucide Icons** & **React Icons**

---

## 🛠️ Instalação e Execução Local

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/BryanDSLL/Portfolio-BZ-DesignAndDev.git
   cd Portfolio-BZ-DesignAndDev
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Gerar build de produção:**
   ```bash
   npm run build
   ```
